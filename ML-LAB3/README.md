# Lab 3

This folder contains the Lab 3 notebook for student survey preprocessing and simple linear regression.

## Contents

- [Lab3.ipynb](Lab3.ipynb) - Lab 3 notebook

## What it covers

- data preprocessing and cleaning
- feature selection and null handling
- simple linear regression experiments
- manual OLS verification
- saving and loading model parameters with pickle

## Requirements

- Python 3.8+ (recommended)
- Jupyter or JupyterLab
- Common data science packages: `pandas`, `numpy`, `matplotlib`, `scikit-learn`

## How to run

1. Open the repository root.
2. Launch Jupyter.
3. Open [Lab3.ipynb](Lab3.ipynb) and run the cells in order.

## Notes

- The notebook expects the survey CSV file to be available in the same folder or in the current working directory used by Jupyter.
